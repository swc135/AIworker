# 规则优先级体系

OpenCode 的 28 条规则按优先级和类别组织，确保安全规则永远优先于功能规则。

## 优先级分层

```
优先级 100 — 安全护栏（不可覆盖）
    99 — 身份与核心约束
    95 — 环境凭据保护
    90 — 命令分级管控
    85 — 操作限制
    ...
    60 — 行为规范
    55 — 对话风格
    50 — 代码质量
    ...
    40 — 工作流自动化
    35 — 部署自动化
    ...
    20 — 基础设施配置
    15 — Git 管理
    10 — 项目管理
```

## 冲突解决

当多条规则对同一行为有不同约束时：

1. **优先级高的规则覆盖优先级低的**
   - guardrail.md（100）设置的安全限制不能被 workflow（40）规则覆盖
   
2. **同优先级时，更具体的规则优先**
   - `no-system-admin-commands.md` 中的具体命令列表优先于通用约束

3. **安全类规则具有否决权**
   - 任何非安全规则不得绕过安全规则

## 规则生效范围

| 范围 | 说明 | 示例 |
|------|------|------|
| 全局 | 对所有会话生效 | guardrail、agent-identity |
| 项目级 | 通过 MEMORY.md 记录 | 用户自定义偏好 |
| 技能级 | 在技能执行期间生效 | deploy-website 内部约束 |

## 动态规则注入

- 全局规则：在 Agent 启动时加载，整个生命周期有效
- 项目级规则：在切换到新工作区时加载 MEMORY.md
- 技能级规则：在技能匹配成功时注入 SKILL.md 的工作流约束
